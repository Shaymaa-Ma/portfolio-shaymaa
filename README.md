# Shaymaa Mashaal — Developer Portfolio

A modern, dark-themed personal portfolio showcasing my work as a Full-Stack Web Developer. Built with HTML, CSS, and JavaScript, the portfolio highlights my projects, technical skills, education, and professional journey through an elegant and fully responsive design.

**Live Demo:** (Add your portfolio URL here)

##  Features

- Modern dark UI with smooth animations
- Fully responsive design for desktop, tablet, and mobile
- Interactive project showcase
- About Me, Skills, Journey, and Contact sections
- Downloadable resume
- Animated statistics and scroll effects
- Professional project cards with live demos and GitHub repositories
- Built with pure HTML, CSS, and JavaScript (no frameworks)

##  Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Shaymaa-Ma/portfolio.git
```

2. Open the project folder.
3. Launch `index.html` in your browser.

That's it—no installation or build process is required.

##  External Libraries

The portfolio uses the following CDN-hosted libraries:

- GSAP
- AOS (Animate On Scroll)
- Font Awesome
- Google Fonts (Fraunces, Inter, JetBrains Mono)
